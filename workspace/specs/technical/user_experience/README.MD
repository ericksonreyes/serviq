# User Experience

This folder documents the UX principles ServIQ should follow when designing customer-facing and tenant-facing experiences. The linked items below point to recommended further reading.

## UX Principles

- [User-centered design](https://www.nngroup.com/articles/ux-without-user-research/) — Start from real user goals, tasks, and context.
- [Clarity](https://www.nngroup.com/articles/aesthetic-minimalist-design/) — Make actions, labels, and outcomes obvious at a glance.
- [Consistency](https://www.nngroup.com/articles/consistency-and-standards/) — Reuse familiar patterns, terms, and behaviors across the product.
- [Accessibility](https://www.w3.org/WAI/fundamentals/accessibility-intro/) — Design for keyboard use, screen readers, contrast, and readable content.
- [Feedback](https://www.nngroup.com/articles/visibility-system-status/) — Show status, success, progress, and failure clearly after every action.
- [Error prevention](https://www.nngroup.com/articles/error-prevention/) — Reduce the chance of mistakes in critical workflows.
- [Recovery](https://www.nngroup.com/articles/error-message-guidelines/) — Help users fix problems quickly when errors do happen.
- [Simplicity](https://www.nngroup.com/articles/signal-noise-ratio/) — Remove unnecessary steps, fields, and visual noise.
- [Mobile-first usability](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) — Ensure the experience works well on small screens and field devices.

## Where These Guidelines Apply

These UX guidelines should influence:

- customer-facing experiences such as browsing, booking, and tracking;
- tenant-facing experiences such as dispatch, support, and administration;
- mobile and desktop flows;
- forms, dashboards, tables, and workflow screens.
