# Workspace Specs

This folder is the canonical documentation hub for shared ServIQ specifications.

## What belongs here

- `PROJECT_PURPOSE.MD` — why this project exists and which engineering capabilities it demonstrates
- `GLOSSARY.MD` — canonical vocabulary for the project
- `AUDIT.MD` — spec audit: contradictions, orphans, and technical risks with their resolutions and status
- `BUILD_SEQUENCE.MD` — dependency-ordered implementation sequence for the 19 services
- `decisions/` — architecture decision records (ADRs): the *why* behind each locked decision
- `domain/` — business boundaries, personas, and assignment strategy documentation
- `technical/` — engineering disciplines, UX guidance, and infrastructure guidance
