# Service Operations

This family groups the tenant-level operational contexts that manage service work from request to completion.

## Contexts

- [Service Management](SERVICE_MANAGEMENT.MD)
- [Customer & Request Management](CUSTOMER_REQUEST_MANAGEMENT.MD)
- [Service Job Management](SERVICE_JOB_MANAGEMENT.MD)
- [Workforce Management](WORKFORCE_MANAGEMENT.MD)
- [Assignment & Dispatch](ASSIGNMENT_DISPATCH.MD)
- [Field Service Execution](FIELD_SERVICE_EXECUTION.MD)
- [Notification](NOTIFICATION.MD)

## Scope

These contexts handle the tenant's operational workflow, job lifecycle, agent capability, assignment, execution, and communication.
