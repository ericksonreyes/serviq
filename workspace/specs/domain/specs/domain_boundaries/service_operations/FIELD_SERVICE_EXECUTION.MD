# Field Service Execution

Once an agent accepts the assignment, the system transitions into **field execution**.

### Responsibility

**How is the work actually performed?**

Core concepts:

```text
Check-in
Work Started
Work Notes
Photos
Parts Used
Customer Signature
Proof of Service
Completion
```

Typical workflow:

```text
Assignment
    │
    ▼
Agent Arrives
    │
    ▼
Check-in
    │
    ▼
Start Work
    │
    ├── Diagnose
    ├── Work Notes
    ├── Photos
    └── Parts Used
    │
    ▼
Complete
    │
    ▼
Customer Confirmation
```
