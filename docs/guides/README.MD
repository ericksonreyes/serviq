# User Guides

Per-channel walkthroughs with **generated** screenshots — ADR-0018: every
visual is produced by `scripts/screenshots/<channel>/*.mjs` and regenerated
on UI change. If a screenshot can't be regenerated by a script, it doesn't
belong in a guide.

## Regenerating

```bash
./scripts/screenshots.sh            # all channels — needs the running stack
./scripts/screenshots.sh --only agent
```

Stack should run the e2e overlay for deterministic AI output:
`docker compose -f services/docker-compose.yml -f services/docker-compose.e2e.yml --profile infra --profile domain --profile ai --profile frontends up -d`

For deterministic *data* as well as deterministic AI, capture after
`./scripts/e2e.sh --fresh` — the bootstrap builds the world on an empty
database, so screenshots show the canonical demo content rather than
accumulated dev artifacts.
