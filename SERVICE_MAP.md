# Service Map

This file lists the services in `services/` and acts as the canonical inventory for the code repositories in this workspace.

Each entry should use a simple per-service record with these fields:

- `name`
- `description`
- `location`

## Example Entries

- name: Customer Portal
  description: Customer Portal PWA
  location: services/serviq-customer-portal-pwa/

- name: Customer Portal BFF
  description: Customer Portal Backend For Frontend
  location: services/serviq-service-provider-portal-bff/
